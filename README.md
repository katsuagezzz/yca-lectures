## 構成

- `index.html` … 第2回（トップページ）
- `26年5月第1回/` `26年第3回/` `26年第4回/` … 各回のページと画像・動画
- `26年第4回/講義教材_自分のAIカンパニーを作る.md` … 第4回の編集元（Markdown）。第4回はこのリポジトリで直接ブラッシュアップしています

- `.github/workflows/deploy-pages.yml` … `main` への push で Pages へ自動デプロイ
