# 経営会議議事録: JDramaShortsの再生回数とフォロワー数を増やす手法

- 日時: 2026-07-24
- 参加: CEO / COO / CFO / CMO(事務局: 社長室)

## 議題

JDramaShortsの再生回数とフォロワー数を増やす手法。

前提: JDramaShortsはオーナーが運営に関わる日本のショートドラマ系動画アカウント。プラットフォーム・現状数値は未確認(社内にデータなし)。確定予算はゼロ。支出・対外公開はオーナー承認事項。

## CFO見解

【財務評価の結論】
現状数値(フォロワー数・平均再生数・収益化導線)が未確定である以上、現時点で広告費等の本格支出を財務として承認推奨できる状態にはない。まずは支出ゼロのオーガニック強化と計測基盤の整備で「フォロワー1人・再生1回の価値(LTV)」を実測し、その上で月額上限を切った少額広告テスト(月1〜3万円規模)のみを「お金をかける価値がある候補」として段階的に解放すべきである。

【前提条件】
※JDramaShortsの実データは本リポジトリ内に存在せず(検索済み)、以下はすべて仮定である。

1. (仮定)プラットフォームはTikTok/YouTube Shorts/Instagram Reels系の縦型ショート動画。フォロワーは数百〜数千規模、平均再生数は数百〜数千回/本の初期フェーズと仮定。
2. (仮定)現時点の直接収益はほぼゼロ。プラットフォーム広告収益分配は Shorts系でRPM(1,000再生あたり)¥10〜30程度、TikTokはさらに低いと仮定。すなわち「再生それ自体」は当面ほぼ収益を生まない。
3. (仮定)オーナーの労働時間は現金支出ではないが機会費用として存在する。外注時の相場は動画編集¥5,000〜30,000/本、実写小規模制作¥10万〜50万/本、AI生成系はその1/3以下(参考教材:中国AI短劇は実写比1/3コスト)。
4. (仮定)広告単価は CPM ¥300〜800、フォロワー獲得単価(CPF)はエンタメ系で¥50〜300/人、PRコラボ投稿の相場はフォロワー単価2〜4円(10万フォロワー級で¥20〜40万/投稿)。
5. 確定予算はゼロ。支出はすべてオーナー承認事項(組織規程7条)。
6. 参考教材の実績データ(3作品: 合計制作費¥28.7M・売上¥25.2M・回収率88%)を「ショートドラマは制作費投下だけでは回収できないことがある」実例として引用する。

【試算】
評価の物差しは2つに統一する。
- フォロワー獲得単価(CPF)=施策費÷増加フォロワー数
- 再生単価(CPV)=施策費÷増分再生数
回収判定は「CPF < フォロワー1人の生涯価値(LTV)」が成立するかで行う。LTV未計測の現状では、この不等式の右辺が不明=広告支出の回収可能性を証明できない、というのが財務上の最重要論点。

施策別コスト構造の比較(月次、仮定値):

| 施策 | 現金支出/月 | 期待CPF | 財務評価 |
|---|---|---|---|
| ①オーガニック強化(フック改善・切り抜き・投稿時間最適化) | ¥0〜3万 | 実質¥0〜数十円 | ◎ 最優先。下振れしても現金損失ほぼゼロ |
| ②投稿頻度増(既存素材の再編集・AI活用) | ¥0〜10万 | 低〜中 | ○ 既存素材の再利用なら限界費用が小さい |
| ③広告出稿(ブースト/プロモート) | 上限設定次第 | ¥50〜300 | △ テスト目的の少額のみ可 |
| ④有償コラボ | ¥20〜40万/回 | ¥100〜1,000超 | × 現段階では割高(無償相互コラボは◎) |
| ⑤多言語展開 | 字幕¥0〜数千/本 | 低 | ○ AI字幕は実質無料。吹替・別アカは型が当たってから |

3か月シナリオ(A: 支出ゼロ運用 / B: A+少額広告テスト 月上限¥3万):

| シナリオ | A: オーガニックのみ | B: A+広告テスト |
|---|---|---|
| 楽観 | 1本がアルゴリズムに乗りフォロワー+1〜5万人、再生累計100万回超 | CPF¥50でフォロワー+約1,800人/3か月を追加 |
| 中立 | フォロワー+2,000〜8,000人、再生累計20〜60万回 | CPF¥150で+約600人/3か月。実測CPF/CPVデータ取得 |
| 悲観 | フォロワー+数百人。現金損失ほぼゼロ、学習データは残る | CPF¥300超。損失上限¥9万で確定 |

要点: Aは悲観でも現金損失がほぼゼロという非対称性を持つ。Bの狙いは実測CPF/CPVという意思決定データを¥9万以内で買うこと。
収益化がPF広告分配のみの場合、フォロワー1人の年間価値は数円〜数十円で広告費は構造的に回収不能。回収が成立するのは下流収益(配信PF売上・コミカライズ・ライセンス等)が接続されたときのみ。

【財務リスク】
1. ベースラインなしの支出は効果測定不能=全額回収不能扱いになり得る
2. 収益化モデル未確定のままの広告費は投資でなく費用
3. 広告フォロワーの質が低くオーガニックリーチを毀損する逆効果リスク
4. 高額単発支出(有償コラボ)は外れた場合の学習も乏しい
5. 隠れコスト(機会費用・外注管理工数・サブスク固定費化)
6. 単一プラットフォーム依存の減損リスク

【CEO/COOへの提言】
1. (CEOへ)支出判断の前に収益化仮説(何で回収するか)の決定を求める
2. (COOへ)フェーズ0として現状数値の棚卸しを実行計画の最初のタスクに
3. ステージゲート型の予算設計: Phase 1(0〜1か月・¥0) → Phase 2(2〜3か月・月上限¥3万の広告テスト、オーナー承認要) → Phase 3(実測CPF<LTV成立時のみ増額上程)
4. 撤退基準の事前設定(例: 広告テスト2サイクルでCPF¥300超が続けば停止)
5. 有償コラボ・吹替多言語・別アカ多面展開はPhase 3以降に見送り(無償相互コラボ・AI字幕は即時実行可)
6. Phase 0の実測値が出た時点で本試算を改訂

## CMO見解

【マーケ評価の結論】
JDramaShortsの成長は「バズ待ち」ではなく設計で作れる。鍵は、(1) プラットフォームが"棚"を持つ鉄板題材への寄せ、(2) 完視聴率70%を狙う冒頭3秒フック＋全話クリフハンガーのフォーマット化、(3) 週5本以上の定量投稿と初動1時間のエンゲージ運用──の3点であり、この順に投資すべき。市場は追い風(世界ショートドラマ市場は2025年110億ドル→2026年推計140億ドル規模)だが競合密度も急上昇しており、ジャンル特化の旗を早く立てた者が勝つ局面にある。

【ターゲットと市場性】
※前提仮定: (a)主戦場はTikTok/YouTube Shorts、(b)日本発ショートドラマの切り抜き・オリジナル配信、(c)英語圏含む海外視聴者にもリーチしうる名称──と仮定。実数値の確認が最優先の宿題。

- コアターゲット(第一仮説): 10〜30代女性。縦型ショートドラマの中心視聴者層。社内教材でもROI 11.5%作品の敗因はこの層との乖離と分析されている。題材はこの層の"棚"(復讐・不倫・格差・正体隠し×恋愛・BL・二面性)から外さない。
- 海外セグメント(第二仮説): 英語名を活かし、J-culture好きの海外視聴者(北米・東南アジア)向けに英語字幕付きで出す。ReelShort約12億ドル・DramaBox 3.23億ドル(2024年)と海外課金市場は実証済みで、日本コンテンツの供給はまだ薄い=ブルーオーシャン寄り。
- 市場性: 世界のマイクロドラマ市場は2025年に約110億ドル、2026年推計140億ドル。日本のショート動画市場も2026年1,530億円見通し。市場の伸び自体はリスクではなく、遅参入がリスク。

【競合状況】
- 国内最大手ベンチマークは「ごっこ倶楽部」: 累計4,000本・総再生100億回・SNS合計620万フォロワー(2025年9月時点)。特徴は「日常の小さな愛」という一貫テーマ＋週次量産体制。学ぶべきは"量産×テーマ一貫性"であり、同テーマ正面対決は不利。
- 配信アプリ勢(ReelShort/DramaBox等331アプリ)は課金型で棚を持つ。無料SNSアカウントとしては競合ではなく、将来的な「切り抜き→送客→ライセンス」の供給側に回れる。
- 社内実証データ(講義教材)が最重要の優位情報: 同予算でROI 150.7%と11.5%の13倍差は「棚の有無」で決まった。題材選定は3原則(棚に並ぶか/盲点を見直すか/視聴者×PFセット設計か)を通してから制作に入る。

【推奨施策】(効果が高い順)
1. 【最優先】題材を"棚"に寄せる編成改革: 次の10本は鉄板フックジャンル(復讐・不倫・格差マウント・正体隠し×恋愛・二面性・BL)に限定。冒頭3秒で「誰が・何をされ・何をやり返すか」を提示。企画段階で1本ごとに「どの棚に載るか」を明文化。
2. アルゴリズム最適化のフォーマット標準化: 完視聴率70%(TikTok)/50%＋ループ(Shorts)が2026年の閾値。全話クリフハンガー終わり、60〜180秒尺、投稿後60分以内のコメント全返信を運用ルール化。
3. 投稿頻度とシリーズ化: 最低週5本。「1シリーズ=20〜30話・全話クリフハンガー」で縦に積み、プロフィール遷移→過去話一気見→フォローの導線を作る。TikTok=発見装置/YouTube=蓄積装置の役割分担。
4. 切り抜き適性の設計: 各話に「過激描写ゼロ＋公開告白のような映像フック」を1つ仕込み、UGC切り抜き・デュエット・ステッチを誘発(UGC再投稿でフォロワー成長+15%、クロスPF展開+32%のデータ)。#jdrama 等の既存需要タグに乗せる。
5. コラボ・トレンド活用: 同規模〜やや上のショートドラマ系・考察系アカウントと無償相互企画。トレンドは「ドラマの世界観に翻訳して」乗る。海外向けには英語字幕2言語運用。
6. (中期)IP分解による二次拡散: 当たったシリーズはキャラ切り抜き・名場面集・コミカライズ等に分解し、各部品を別導線の集客装置にする(1本→10ビジネスの講義原則)。

【マーケリスク】
- 前提未確認リスク(最大): アナリティクス確認前の大規模投資は不可
- 総括誤りリスク: 「ジャンルが当たった」と誤読すると次で外す。ヒット要因は必ずデータ+外部の目で検証
- 量産による品質劣化・ブランド希薄化: 週5本体制はテンプレ化とセットでないと破綻
- プラットフォーム依存リスク: 最低2PF並行+フォロワーのオウンド接点(公式LINE等)化を推奨
- 偽エンゲージメント厳禁: 購入フォロワー等は検出強化で配信抑制の実害があり、検討すら不可

【CEO/COOへの提言】
- CEOへ: JDramaShortsを「棚検証済みIPの入口(発見装置)」と定義することを提言。KPIに完視聴率・リピート視聴率・シリーズ完走率を追加されたい。ジャンル特化の旗(例:「二面性×学園」「復讐×配信社会」)の決定はCEO裁定を仰ぐ。
- COOへ: ①現状アナリティクス棚卸し(1週間)→②投稿テンプレとシリーズ企画の標準化(2週間)→③週5本運用開始→④30日後に完視聴率で題材入替、の順を推奨。初動60分コメント返信のオペレーション設計と切り抜き素材の量産体制(AI活用)はCOO領域。

## CEO結論

【結論】
会社方針として、COOの2段構え(Phase 0: 現状把握 5日 → Phase 1: 30日検証サイクル)を実行計画の骨格に、CMOの「棚に寄せる編成・フォーマット標準化・定量投稿」をコンテンツ方針に、CFOのステージゲート型予算(Phase 1は支出ゼロ)を財務規律として採択する。最初の30日の目的は収益化ではなく「勝ちパターンの仮説検証」とし、広告等の支出はPhase 2以降にオーナー承認を得て段階的に解放する。

【根拠】
1. 三役員の見解は対立しておらず、「まず計測、次に支出ゼロの型検証、支出はその後」という順序で三者一致している。この順序をそのまま会社方針とする。
2. フォロワーLTV未計測の段階では広告支出の回収可能性を証明できず、オーガニック強化は下振れでも現金損失ほぼゼロという非対称性を持つ。確定予算ゼロの当社にとって合理的な唯一の初手である。
3. CMOの「棚」理論は社内教材の実証(同予算でROI 150.7% vs 11.5%)に裏付けられており、支出ゼロで実行可能なため、Phase 1の題材検証に組み込める。
4. COOの週次サイクルはCMO施策を検証可能な形に分解しており、Day 35に「勝ちパターン仕様書v1」という具体的成果物で締まる。

COO確認事項への回答:
- ①承認。Phase 1の完了条件は「勝ちパターン仮説の検証」であり収益化ではない。
- ②週次本数はオーナー確認事項。CEO暫定方針は「週3本を下限コミット、週5本を目標」。オーナー作業1本10分以内の体制を前提条件とする。
