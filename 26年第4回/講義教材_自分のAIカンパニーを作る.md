# 第2部：エージェントとは何か（5–15分）

## チャットとエージェント

| | チャット（これまでの使い方） | エージェント（今日からの使い方） |
|---|---|---|
| 起点 | あなたが聞くと、答えが返ります | あなたが任せると、進めます |
| 単位 | 1回ごとに会話が終わります | 調べる・作る・確かめる・報告する |
| 手足 | ありません | ファイルもスクリプトも動かせます |
| 記憶 | 今日の分だけです | 決定と数字を記録に残します |

違いは能力ではなく、**与えたもの**です。

## 2-1 エージェントの3点セット

**役割 ＋ 道具 ＋ 記憶 ＝ AI社員**

- **役割**：何の担当か／何を決めてよいか
- **道具**：ファイル・検索・スクリプト・投稿
- **記憶**：数字の履歴・決定事項・失敗

## 2-2 自走のループ

```
計画 → 実行 → 確認 → 報告 →（計画へ戻る）
```

- 計画：作業手順に分けます
- 実行：作って、出します
- 確認：数字で確かめます
- 報告：次の一手を出します

人間の出番は、最初の1回と、承認だけです。チャットは「聞いて終わり」で止まりますが、エージェントは確認の結果が次の計画に戻ります。

# 第3部：組織を設計する（15–28分）

## 基本のかたち

```
あなた（オーナー）── 決めること・承認すること
 └── CEO（まとめ役・裁定）
      ├── COO（制作と実行）
      ├── CFO（お金と採算）
      └── CMO（数字と打ち手）
```

指示は上から、報告は下から。この線を文章で書いたものが**組織規程**です。
最小構成なら2人でも動きます（制作担当・分析担当）。

## 3-1 社員の定義（1人＝1ファイル）

| 役職 | 決めること | 出すもの |
|---|---|---|
| CEO | 意見が割れたときの結論 | 方針と、その理由 |
| COO | 作業の手順と順番 | 完成した制作物 |
| CFO | その支出が見合うか | 試算と、上限額の提案 |
| CMO | 次に変える1か所 | 数字の読みと施策案 |

書く項目は4つだけです ── 担当／判断してよい範囲／専門外のときの差し戻し先／報告の書き方。

## 3-2 権限を3段に分けます

| 段 | 範囲 |
|---|---|
| AIが決めてよい | やり方・順番・表現の候補出し・下書き・検証 |
| 相談してから決める | 新しい取り組み・外部との約束・素材の使い方 |
| あなたが決める | お金・公開・方向転換・そして結果の責任 |

ここを先に書いておくと、いちいち止まらなくなります。止まる回数が、そのまま運用の重さになります。

## 3-3 会社の中身は、テキストです

```
my-company/
├ .claude/agents/   ← 社員の定義（1人1ファイル）
│   ├ ceo.md ／ coo.md
│   └ cfo.md ／ cmo.md
├ company/
│   ├ 組織規程.md   ← 指示系統と、権限の3段
│   ├ minutes/      ← 議事録（自動で残ります）
│   └ orders/       ← 発注書と、納品物
└ data/             ← 数字の記録
```

| 項目 | 値 |
|---|---|
| 設立にかかる費用 | ¥0 |
| 登記・定款・資本金 | 不要 |
| 社員を1人増やす手間 | 1ファイル |
| 最初の設立にかかる時間 | 30分 |

## 3-4 設立に使う文（そのまま送っていただけます）

**01：**
> AIカンパニーを作りたいです。CEO・COO・CFO・CMOの4名で、組織と指示系統を作ってください。何をするかはまだ決めていません。

→ 役員の定義ファイルと組織規程が出てきます。

**02：**
> 決裁権限表を作ってください。AIが決めてよいこと、相談してから決めること、私が決めることの3段に分けてください。

→ 止まる場所と、進んでよい場所が決まります。

※ 最小構成で始めるなら、**01** の「CEO・COO・CFO・CMOの4名で」を「**制作担当と分析担当の2名で**」に書き換えてください。増員は、あとから1ファイルです。

# 第4部：仕事を渡す（28–42分）

## 4段のフロー

| 段 | 内容 | 担当 |
|---|---|---|
| 1 ミッション | 1行で書きます（例：「私のTikTokの再生数を増やしてください」） | **あなた** |
| 2 発注書 | 1行を、実行できる大きさに割ります | CEO |
| 3 納品 | 作って、確かめて、出します | COO |
| 4 計測 | 数字を読み、次の1手に戻します | CMO |

あなたが触るのは 1 と、4 のあとの承認だけです。

## 4-1 発注書に書く5項目

1. **目的**：何のためにやるのか
2. **完成の条件**：どうなったら終わりか（数字で）
3. **期限**：いつまでに
4. **使ってよい素材**：権利の範囲
5. **報告の形式**：毎回そろえます

※ 2 が一番だいじです。「いい感じに」は条件になりません。この様式を1つ作ると、以降は使い回しになります。

## 4-2 1週間の回り方

| 曜日 | 内容 | 担当 |
|---|---|---|
| 月 | 先週の数字を読みます。落ちた指標を1つだけ特定します | CMO |
| 火–金 | 作って、出します。制作と投稿はここに寄せます | COO |
| 土 | 1つだけ変えます。2つ変えるとどちらが効いたか分からなくなります | **あなた** |
| 日 | 議事録を残します。決めたことと、その理由だけで十分です | CEO |

週1回、決まった曜日に回します。回数ではなく、続くことが効きます。

## 4-3 つまずく場所は、だいたい3つです

| つまずき | 対処 |
|---|---|
| 目的があいまい | 完成の条件を数字で書きます（「増やす」ではなく「週3本、平均1,000回」） |
| 権限があいまい | 3段の表を先に作ります。判断のたびに止まると、手作業より遅くなります |
| 記録が残らない | 報告の形式を固定します。書式がそろって初めて、比べられます |

## 最初の発注に使う文

**03：**
> ミッションは「（ここに1行）」です。今週の発注書を1枚作ってください。目的・完成の条件・期限・使ってよい素材・報告の形式の5項目でお願いします。

→ 1行が、今週の作業に変わります。

# 第5部：資産として積み上げる（42–52分）

## 3つの層

| 層 | 中身 |
|---|---|
| ① 組織そのもの | 社員の定義ファイル |
| ② データ | 数字の履歴と、その解釈 |
| ③ 作品 | 公開したもの |

目に見えるのは③だけですが、次の1本を軽くしているのは①と②です。

## 5-1 消えるもの、残るもの

| 消えるもの | 残るもの |
|---|---|
| 単発の投稿 | 公開した作品 |
| 思いつきのアイデア | 数字の履歴と、その解釈 |
| 頭の中にだけある勘 | 動く工程（スクリプト・手順） |
| チャットの会話履歴 | 社員の定義ファイル |

## 5-2 人間が残っている場所

| 仕事 | 中身 | AIに渡さない理由 |
|---|---|---|
| ミッションを決める | 何を目指すのか | 目的はオーナーのものです |
| どの瞬間を選ぶか | 切り抜くシーン、サムネの顔 | センスは、あなたの資産です |
| どの言葉に凝縮するか | タイトルの一文 | 刺さる言葉は文脈そのものです |
| 承認と責任 | お金・公開・方向転換 | 責任はAIには取れません |

> 資産とは、次の1本を軽くしてくれるものです。作品は増え、工程は残り、会社そのものがあなたの持ち物になります。

## Q&A（想定問答）

- **プログラミングができなくても作れますか** → 作れます。組織づくりと発注はすべて日本語の文章です。スクリプトが必要な場面も、書くのはAIの側です
- **社員は何人から始めるとよいですか** → 2人（制作担当・分析担当）をおすすめします。4人はきれいに見えますが、最初は会議の回数が増えるだけになりがちです
- **毎月いくらかかりますか** → 設立は0円です。継続的にかかるのはAIの利用料だけです。上限額を先に決めてCFO役に見張らせてください。無料枠でも最初の1か月は回ります
- **AIが勝手に変なことをしませんか** → 権限の3段を書いていないと起こります。お金・公開・外部との約束は必ず「あなたが決める」に置いてください
- **題材が思いつきません** → 今持っているアカウントで構いません。フォロワーが少ないほど変化が数字に出やすく、教材としては有利です
- **途中で飽きたらどうなりますか** → 止まるだけで、消えはしません。定義ファイルと数字の履歴が残るので、再開は「先週の続きから」で通じます
